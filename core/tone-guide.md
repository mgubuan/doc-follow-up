# Tone

Warmth stays the same on every touch. A later email may add one factual sentence about the deadline. It does not get colder, sharper, or more formal. Do not put the touch count in the subject or the body.

The older line "no tone escalation" and a final-notice ladder are the same rule, read this way: specificity can go up (name the file, the period, the deadline on file). Warmth does not go down. This version does not ship a three-stage marketing ladder. The templates are neutral placeholders until a copy pass replaces them.

## Use

- "Hope you are doing well."
- "We still need the documents below."
- "The deadline on file was 2026-09-12."
- "Thank you for sending this."

## Do not use

- "As previously stated..."
- "Per our last email..."
- "This is our fourth request..."
- "Follow-up #3" in a subject
- A subject that starts with the firm name and `--`
- Any sentence that blames the client
- A consequence you invented. The only impact you may name is the client-facing reason already on the row.
- Anything from internal notes, including a softened version of it

## The test

Would you be comfortable receiving this from your own accountant? If it would make you feel nagged, guilty, or defensive, rewrite it.

Run one more check before showing it: no four-word run from `internal_notes` appears in the draft.
