# Follow-Up Schedule

All follow-up cadence is driven by one variable: days remaining until the deadline. No subjective priority labels.

## Schedule by Days Remaining

### 10+ days to deadline (Comfortable)

| Day | Action |
|-----|--------|
| 0 | Initial request |
| Halfway to deadline | First reminder |
| 3 days before deadline | Second reminder |
| Daily after that | Daily reminder until deadline |

### 5-9 days to deadline (Moderate)

| Day | Action |
|-----|--------|
| 0 | Initial request |
| 2 | First reminder |
| 4 | Second reminder |
| Daily after that | Daily reminder until deadline |

### 2-4 days to deadline (Tight)

| Day | Action |
|-----|--------|
| 0 | Initial request |
| 1 | First reminder |
| Daily after that | Daily reminder until deadline |

### Overdue (past deadline)

| Day | Action |
|-----|--------|
| 0 | Immediate request with overdue acknowledgment |
| 1 | Follow-up |
| Every 2 days | Continued follow-up every other day |

## Hard Ceiling

After 4 follow-ups with no response at ANY tier, stop emailing. Flag the item for a phone call or direct conversation.

## Overdue Language

When an item is past its deadline, the email MUST:
- Acknowledge the deadline has passed
- Explain the downstream impact (delays service delivery, pushes other deadlines)
- Remain friendly and professional (never punitive)

## Grouping Rule

When a client has multiple open items due for follow-up on the same day, send ONE email listing all items. Never send multiple separate emails to the same client on the same day.

## Tone (constant)

Every follow-up is friendly and professional. No tone escalation. No passive aggression. No guilt. These are busy business owners. Treat them with respect at every stage.
